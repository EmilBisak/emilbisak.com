# Emil Bisak portfolio

The visual edition of my portfolio, live at **https://emilbisak.com**.

A dark, hand-built page with a light ribbon drawn in WebGL that flows through the content as you scroll.

The same content in a cleaner, technical design is at **https://e-b.dev** ([EmilBisak/e-b.dev](https://github.com/EmilBisak/e-b.dev)).

## Inside

- `index.html`: the content
- `style.css`: layout and styles
- `main.js`: navigation, reveals and the small interactions
- `scene.js`: the WebGL ribbon, with adaptive quality, reduced motion and a fallback when WebGL is unavailable

Plain HTML, CSS and JavaScript, with no framework and no build step, served by GitHub Pages.
